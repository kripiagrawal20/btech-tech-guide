# B.Tech Tech-Guide

A beginner-friendly guide for B.Tech CSE/IT students to understand what to learn, why it matters, and what to do next.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Stack

- React and Vite
- JavaScript
- Tailwind CSS
- React Router
- Local static content in `src/data/`

## Main sections

- Start Here and the year-wise roadmap
- Platforms and resource explainers
- Career paths and beginner guides
- Glossary, project ideas, and internship guidance

The site is a learning guide and does not replace the official services it describes. Check each provider's official website for current details.
